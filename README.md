# Психологический бот-помощник для работы с тревожностью

Этот бот реализует комплексную систему помощи людям с тревожными расстройствами, основанную на принципах когнитивно-поведенческой терапии (КПТ).

## 🚀 Возможности

### 📊 Эмоциональный трекер
- **Запись эмоций** с указанием интенсивности до и после выполнения техник
- **Анализ негативных мыслей** с выявлением когнитивных искажений
- **Ежедневные записи** с оценкой настроения, ресурса, тревожности и сна
- **Автоматическое извлечение данных** из текста пользователя с помощью ИИ

### 🧘‍♀️ КПТ техники
- **Дыхательные упражнения**: 4-7-8, дыхание по квадрату
- **Техники заземления**: 5-4-3-2-1, описание окружения
- **Релаксация**: прогрессивная мышечная релаксация
- **Осознанность**: медитация, осознанное дыхание
- **Когнитивные техники**: остановка мысли, вызов негативных убеждений

### 📈 Визуализация прогресса
- **Графики настроения** с трендами и средними значениями
- **Динамика тревожности** с цветными зонами комфорта
- **Эффективность техник** в виде столбчатых диаграмм
- **Недельные сводки** с комплексным анализом показателей

### 📚 PDF-гайды
- **Мотивационный гайд** с научными фактами и вдохновляющей информацией
- **Инструкции по техникам** с пошаговыми описаниями
- **Персонализированные рекомендации** на основе данных пользователя

### 🤖 ИИ-анализ
- **Автоматическое распознавание** эмоций и мыслей в тексте
- **Выявление когнитивных искажений** по ключевым словам
- **Персонализированные рекомендации** техник
- **Анализ эффективности** различных подходов

## 📋 Команды бота

### Основные функции
- Ежедневная проверка состояния
- Трекинг эмоций и мыслей
- Доступ к КПТ техникам
- Доступ к PDF-гайду (скрыт из гитхаб)
- Просмотр статистики и графиков тревожности

### Естественное общение
Бот понимает естественную речь и автоматически:
- Распознает записи эмоций по ключевым словам
- Анализирует негативные мысли
- Обрабатывает ежедневные записи
- Предлагает подходящие техники


## 📊 Аналитика и отчеты

Бот автоматически собирает и анализирует:
- Тренды настроения и тревожности
- Эффективность различных техник
- Паттерны в поведении пользователя
- Прогресс в работе с когнитивными искажениями

## 🔒 Конфиденциальность

- Все данные пользователей хранятся в базе SQLAlchemy и не передаются автору и третьим лицам
